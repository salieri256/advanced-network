## ✅ 動作確認

### BGP メッセージ

|タイプコード|タイプ名称|役割|
|:-:|:-|:-|
|1|OPEN|接続関係を確立するために最初に使うメッセージ。<br>✅ バージョン<br>✅ 所属 AS 番号<br>✅ ホールドタイム<br>✅ BGP ID<br>✅ オプションパラメーター長<br>✅ オプションパラメーター|
|2|UPDATE|経路情報を通知するためのメッセージ。<br>✅ 宛先ネットワークのアドレス<br>✅ パス属性<br>など|
|3|NOTIFICATION|エラーを通知するためのメッセージ。<br>✅ エラーコード<br>✅ エラーサブコード<br>✅ エラーに関するデータ|
|4|KEEPALIVE|BGP ピアの正常性を確認するためのメッセージ。定期的に交換される。|
|5|ROUTE-REFRESH|経路情報の再送信を要求するためのメッセージ。<br><hr>💡 別途通知が必要 (OPEN メッセージ)|

|属性タイプコード|パス属性|周知の要否|役割|
|:-:|:-|:-|:-|
|1|ORIGIN|❗️ 必須|NLRI の起源を示す。<br>IGP、(EGP)、INCOMPLETE のいずれかの値をもつ。|
|2|AS_PATH|❗️ 必須|NLRI が通過してきた AS 番号のリスト。<br>NLRI に到達するために経由する AS の数が分かる。|
|3|NEXT_HOP|❗️ 必須|NLRI へ到達するためのネクストホップの IP アドレスを示す。|
|4|MED<br>(MULTI_EXIT_DISC)|必須ではない|隣接 AS との間に複数の回線がある場合に、それらの優先度を示す。<br>値の小さい方が優先度が高い。|
|5|LOCAL_PREF|必須ではない|AS 内での経路の優先度を示す。<br>値の大きい方が優先度が高い。|
|8|COMMUNITY|必須ではない|NLRI に経路制御上の意味を持たせたタグ (32 ビットの整数値) を付与する。<br>「経路に色をつける」を例えられる。|
